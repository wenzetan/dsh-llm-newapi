# dsh 0.1.5-rc.1 / dsh-llm-newapi 0.8.6-rc.2 实施计划

> 执行边界：仅支持 dsh 0.1.5-rc.1；只完成非 Web 本地验证。不得修改、重启当前承载会话的 dsh Web，不得 push、打 tag 或发布 npm/GitHub Release。

## 文件职责与变更边界

- `package.json`、`package-lock.json`：插件版本、DSH dev/peer 依赖与 RC 缺包 overrides。
- `src/index.ts`：运行时最低宿主版本和精确升级提示。
- `src/types.ts`、`src/translate.ts`：OpenAI usage wire 类型与可信 `totalTokens` 映射。
- `src/adapter.ts`、`src/client/locale.ts`：不假设直连路径的 models.dev 网络诊断。
- `test/host-compat.mjs`、`test/fixtures/dsh-llm-0.1.5.exports.json`：0.1.5 线实际导出面、ESM 链接与 0.1.2 明确拒绝。
- `test/smoke.mjs`：usage 边界与代理诊断行为回归测试。
- `.github/workflows/ci.yml`：plugin-check 与 boot 固定到 dsh 0.1.5-rc.1，保留原有强断言。
- `README.md`、`README.zh-CN.md`、`DESIGN.md`、`docs/*.md`、构建脚本注释：同步当前支持边界、代理语义和候选状态；历史 rc.1 计划保留历史版本事实。
- `lib/**`：由构建生成且必须与源码一致。
